나이스 출결 ↔ 활동 참여 여부 대조기 (다중 반 지원)

반별 나이스 일일출결현황 엑셀 파일을 올리면 병합 셀을 자동 복원하여 활동 날짜·교시와 대조합니다. (모든 데이터는 브라우저 로컬에서만 처리되며 외부 서버로 전송되지 않습니다)

1. 반별 출결 엑셀 파일 올리기 (여러 개 가능)

여기를 클릭하거나 반별 엑셀 파일(.xlsx, .xls, .csv)을 끌어다 놓으세요
• 파일명에 반 이름이 있으면(예: 1반_출결.xlsx, 2-3.xlsx) 자동 입력되며 직접 수정 가능합니다.
• 나이스 병합 셀(연속 출결 학생)을 자동으로 채워서 읽습니다.

2. 확인할 날짜 및 활동 교시 설정

활동 교시 선택 (체크 안 하면 교시 무관 전체 확인)

3. 대상 학생 명단 입력 (엑셀 복붙 가능)

• 출결 파일 목록의 '반' 표기(예: 1반)와 명단의 '반' 표기(예: 1 또는 1반)는 자동으로 맞춰집니다.
